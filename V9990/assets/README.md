# Port assets

The build reads PNG, JPEG, JSON and other data here as inputs for the MSX cartridge. The opening illustration is in opening.jpg. Stage and mission folders contain the art used by the port. The editable robot path table in step4/robot-paths.json contains per-frame lists of robot ID, X, Y and packed view and size.

Original ROMs and raw captures remain local. See the [build guide](../../docs/BUILDING.md) for the game inputs. Graphics and marks of the original game belong to their rights holders.
