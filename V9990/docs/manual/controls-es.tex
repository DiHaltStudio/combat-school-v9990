\textbf{Carrera y fuerza.} Pulsa y suelta repetidamente. Si mantienes el botón apretado, no mantendrás la barra \texttt{POWER}. En las barras elevadas, sigue pulsando para avanzar colgado.

\textbf{Patadas.} Contra el instructor, combina abajo y patada para barrer, o arriba y hacia él con patada para dar una patada alta. Pulsa patada al principio de un salto para atacar en el aire.
